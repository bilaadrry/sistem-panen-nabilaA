# Sistem Penghitung Hasil Panen

## Deskripsi Singkat
Program Python sederhana berbasis terminal untuk menghitung total berat hasil panen harian, total biaya penjualan, serta perhitungan potongan harga (diskon panen).

## Cara Menjalankan Program
1. Pastikan Python sudah terpasang pada komputer Anda.
2. Unduh atau clone repositori ini ke komputer lokal:
   git clone https://github.com/bilaadrry/sistem-panen-nabilaA.git
3. Masuk ke direktori proyek:
   cd sistem-panen-nabilaA
4. Jalankan program menggunakan perintah:
   python hitung_panen.py
